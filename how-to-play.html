How to play Elementle

Find the day’s mystery chemical element in eight guesses. The goal is not only to get the answer, but to use each clue to narrow the periodic table intelligently.

1. Enter an element

Start typing the name of a chemical element in the answer box and choose the matching suggestion. Elementle accepts the elements in the periodic table, from hydrogen to oganesson. Submit your choice with the Guess button or the Enter key.

2. Read the atomic-number arrow

Every element has an atomic number: the number of protons in one atom of that element. Elementle shows an arrow beside a submitted guess. An upward arrow means the mystery element has a higher atomic number; a downward arrow means it has a lower atomic number. A celebration icon means the atomic number is an exact match.

That turns the periodic table into a useful search range. For example, if a guess of element 40 points upward and a later guess of element 80 points downward, the answer lies between those two positions.

3. Use symbol-letter feedback

Each element has a one- or two-letter chemical symbol. Green symbol letters are correct and in the right position. Yellow symbol letters belong in the mystery symbol but are in the wrong position. Letters without either colour do not appear in the symbol. This feedback is especially helpful once the atomic-number range is small.

4. Notice the element family

Elementle also shows a family label, such as noble gas, halogen, transition metal or nonmetal. A green family label means your guess belongs to the same family as the answer. Families collect elements with related outer-electron structures, so they often share familiar properties: noble gases are notably unreactive, while alkali metals are famously reactive.

5. Ask for a hint when you need one

The Hint button gives one science clue about the day’s element. Hints can point to an everyday use, a property, a discovery, or a role in nature. A hint is there to make the puzzle approachable, not to penalise curiosity.

6. Come back tomorrow

There is one shared puzzle for each local calendar day. When the countdown reaches midnight, a fresh mystery element becomes available. Your game can be played without an account; creating an account lets Elementle sync progress and statistics across devices.

A useful first strategy

Begin with a recognisable element from a different part of the table, then let the direction arrow do most of the work. Use the family clue to choose a better next guess and save the symbol feedback for the final stretch. There is no single perfect opening guess—the game rewards forming and testing a small hypothesis from the information already on the board.
